One-line: a square, icon-only button for toolbars and card actions.

```jsx
<IconButton label="Close" variant="ghost">×</IconButton>
```

Sizes are 32/40/48px — keep to 44px+ for touch targets. Pair with the official gold-circle `BrandIcon` set only for decorative marks; inside an IconButton use a plain glyph or a line icon so the control reads as interactive.
